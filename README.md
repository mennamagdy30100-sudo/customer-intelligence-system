# Customer Intelligence System

نظام ويب بيعرض سلوك كل عميل: بيشتري إيه، وإمتى، بالعروض ولا بالسعر العادي، وإيه الإجراء أو العرض المناسب ليه.

## هيكل المشروع

```
Customer_Intelligence_System/
├── data/        الملفات الستة (CSV)
├── notebook/    01_Data_Exploration.ipynb  (تجهيز وفحص الداتا)
├── scripts/     build_profiles.py          (التحليل: بيطلّع ملف لكل عميل)
├── outputs/     نتايج التحليل (JSON/CSV) اللي الموقع بيقراها
└── web/         app.py (Flask) + templates + static (HTML/CSS/JS)
```

## التشغيل

من الـ Terminal جوه فولدر المشروع:

```
python -m pip install flask pandas numpy
python scripts/build_profiles.py     # فولدر data لازم يكون موجود. بياخد حوالي 30 ثانية
python web/app.py
```

وبعدين افتحي المتصفح على: http://127.0.0.1:5000

لو الأمر `python` مش شغال عندك، استخدمي المسار الكامل لـ Python بتاع Anaconda بدله.
لو مش عايزة تعيدي التحليل، ملفات `outputs/` الجاهزة كفاية لتشغيل الموقع.

## الموقع بيعرض إيه؟

- **الصورة العامة:** أهم 4 حاجات الداتا بتقولها على مستوى الشركة (محسوبة تلقائي).
- **قايمة العملاء:** بحث وفلاتر، وفلتر "غايب عن معتاده".
- **ملف العميل:** خلاصة بالكلام، عروض مقترحة ومعاها السبب، واستنتاجات ومعاها قوة الدليل، وبعدها الأرقام والرسوم.

## الـ API

| الرابط | بيرجّع |
|---|---|
| `/api/overview` | الصورة العامة والملخص |
| `/api/customers?q=&city=&user_type=&segment=&status=&sort=&limit=` | قايمة العملاء (`status=lapsed` أو `active`) |
| `/api/customers/<user_id>` | ملف عميل كامل |
| `/api/filters` | القيم المتاحة للفلاتر |

## قواعد التحليل (أول `scripts/build_profiles.py`)

- الحسابات على الطلبات **المُسلَّمة (Delivered)** بس. الملغي والمرتجع بيتحسب في نسبة المشاكل.
- `fact_orders` على مستوى البند، فالطلب بيتحسب بـ `order_id`.
- **الإجازة** = الجمعة والسبت + قايمة `HOLIDAYS` (تواريخ تقريبية، وبعضها بيتحرك حسب رؤية الهلال، راجعوها).
- **العميل الغايب** = آخر طلب له أطول من ضعف الفترة المعتادة بين طلباته (وأكتر من 60 يوم).
- **قوة الدليل:** أي نمط (فئة مفضلة، إجازات، خصومات، قناة) بنختبره إحصائيًا قبل ما نقوله. "مؤكد" و"إشارة ضعيفة" و"لا يوجد نمط" و"بيانات قليلة". ولو الأنماط من نوع معين على مستوى كل العملاء قريبة من الصدفة، بتتعلّم "غالبًا صدفة".

## اللي الداتا الحالية بتقوله (وقت آخر تشغيل)

- الإجازات مش بتزوّد المبيعات.
- العملاء النشطين نزلوا حوالي 30% بين أول 3 شهور وآخر 3 شهور، وحوالي 750 عميل غايبين عن معتادهم. **ده أوضح وأهم استنتاج.**
- الخصم مابيزوّدش عدد القطع في الطلب، فالخصم الأفضل يتوجّه للعميل الغايب بس.
- أنماط الإجازات والخصومات والفئات المفضلة لكل عميل قريبة من الصدفة. **القناة (أونلاين/فروع) هي النمط الفردي الوحيد اللي طلع واضح.** ولو الداتا دي تجريبية، النظام هيطلّع أنماط أوضح لما تتحط عليه داتا حقيقية.
- كل العروض المقترحة اقتراحات للتجربة (جرّبوها على مجموعة صغيرة وقارنوا)، مش نتايج مضمونة.
